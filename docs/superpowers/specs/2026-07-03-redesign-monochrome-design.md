# Редизайн devtechblog.ru — «Инженерный монохром»

**Дата:** 2026-07-03
**Сайт:** devtechblog.ru (Quartz v5.0.0)
**Статус:** дизайн утверждён пользователем (по макетам), ожидает реализации
**Макеты:** артефакт «три направления», выбран вариант A + обе темы

## Цель

Технический, сдержанный, оригинальный и лёгкий вид. Не должен выглядеть
«сгенерированным»: без градиентов, теней, скруглённых карточек, стоковых тем.
Характер — из дисциплины: монохром + один акцент, тонкие линейки, mono для
служебного, читаемый текст.

## Решения (подтверждены пользователем)

- **Направление:** «инженерный монохром» (вариант A из макетов).
- **Темы:** светлая и тёмная, одна логика, переключатель остаётся.
- **Шрифты:** как в макете — системные стеки, ноль веб-шрифтов.
- **Чистка компоновки:** отключить граф связей, режим читателя, обратные
  ссылки. Остальная компоновка не меняется.
- **Тема border удаляется** (−688 КБ CSS).

## Типографика

Ноль загрузки веб-шрифтов. Полные стеки задаются в `custom.scss` через
переопределение переменных Quartz:

```scss
:root {
  --titleFont: "Segoe UI", system-ui, Roboto, Arial, sans-serif;
  --headerFont: "Segoe UI", system-ui, Roboto, Arial, sans-serif;
  --bodyFont: "Segoe UI", system-ui, Roboto, Arial, sans-serif;
  --codeFont: "Cascadia Code", ui-monospace, "JetBrains Mono", Consolas, monospace;
}
```

- Заголовки: тот же гротеск, вес 700, `text-wrap: balance`.
- Меты статьи (дата, время чтения), хлебные крошки, теги, шапка сайта — mono,
  мелкий кегль, для капса — letter-spacing ~0.1em.
- Плагин `fonts` (github:quartz-community/fonts) отключить, `cdnCaching`
  и `fontOrigin` привести к состоянию «ничего не грузим с CDN» — точный
  механизм подтверждается спайком в плане (см. Риски R1).

## Чистка компоновки

В `quartz.config.default.yaml` поставить `enabled: false` (код плагинов не
трогаем, файлы не удаляем):

- `github:quartz-community/graph` — уходит pixi.js, самый тяжёлый JS;
- `github:quartz-community/reader-mode`;
- `github:quartz-community/backlinks`.

Остаётся: слева — заголовок сайта, поиск, переключатель темы, дерево заметок
(explorer); справа — только оглавление (TOC); над статьёй — хлебные крошки,
заголовок, меты, свойства заметки.

## Характер (детали в custom.scss)

- Шапка сайта (`PageTitle`): `DEVTECHBLOG.RU` — mono, капс, разрядка 0.12em.
- Хлебные крошки стилизуются как mono-«бровка»: капс, мелко, приглушённо,
  разделитель `·`. Компоненты не меняем — только CSS.
- `h2` в статье: линейка 1px снизу (`border-bottom: 1px solid var(--lightgray)`).
- Линейка 1px под шапкой и над футером.
- Код-блоки: фон светлее/темнее фона страницы на полтона
  (светлая: `#EEF0F2`, тёмная: `#1D2126`), бордер 1px `var(--lightgray)`,
  радиус ≤ 6px.
- Никаких box-shadow, градиентов, скруглений больше 6px.
- Пилюля «Развернуть код» (плагин collapse-code) уже использует
  `var(--secondary)`/`var(--light)` — перекрасится автоматически, проверить
  визуально в обеих темах.

## Удаление темы border

Из `quartz.config.default.yaml` удалить запись плагина
`github:saberzero1/quartz-themes` (subdir: plugin). После — `npx quartz plugin
prune` (опционально) и пересборка: инжект ~688 КБ CSS исчезает.

## Реализация — поверхность изменений

Ровно два файла + конфиг, исходники Quartz не патчим:

1. `quartz.config.default.yaml` — палитры, отключение 4 плагинов
   (quartz-themes удалить, graph/reader-mode/backlinks выключить),
   настройка шрифтов/fontOrigin.
2. `quartz/styles/custom.scss` — переменные шрифтов, все детали характера
   (сейчас файл пуст — это штатная точка кастомизации).

## Бюджет веса (до → после)

- CSS: ~700 КБ (тема border + база) → ~30 КБ суммарно.
- Шрифты: 4 веса JetBrains Mono с Google CDN → 0 (системные).
- JS: минус pixi.js (граф).

## Риски и проверки

- **R1 — механизм отключения веб-шрифтов.** Как именно v5 грузит шрифты
  (плагин `fonts` vs `theme.fontOrigin`) — подтвердить спайком: после
  изменений в собранном HTML не должно быть ссылок на fonts.googleapis.com /
  fonts.gstatic.com. Если `fontOrigin: local` недостаточно — переопределение
  переменных в custom.scss всё равно даёт нужные шрифты, остаётся лишь
  убрать лишние `<link>`.
- **R2 — og-image.** Плагин генерации OG-картинок может использовать шрифты
  темы; после изменений сборка должна проходить, OG-картинки — генерироваться.
- **R3 — остатки темы border.** После удаления плагина проверить, что в
  `public/` нет resource-style с маркерами темы (`--accent-dark-h`).
- **R4 — collapse-code в обеих темах.** Визуальная проверка свёрнутого блока
  (fade от `var(--light)`, пилюля) в светлой и тёмной темах.
- **R5 — explorer/поиск после чистки.** Убедиться, что левая колонка выглядит
  цельно без графа/бэклинков, поиск работает.

## Тестирование

- `npx quartz build` проходит; в HTML нет ссылок на Google Fonts (R1) и
  маркеров темы border (R3).
- Визуальная проверка обеих тем локально (`npx quartz build --serve`):
  статья с кодом, свёрнутый блок, explorer, поиск, TOC.
- Замер веса: суммарный CSS в `public/` до/после.

## Вне охвата (YAGNI)

- Правки компонентов/TSX и layout.byPageType.
- Кастомный логотип/фавикон.
- Изменения контента.
- Деплой — отдельный, запускаемый пользователем шаг.
