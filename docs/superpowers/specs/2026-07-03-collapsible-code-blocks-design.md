# Сворачиваемые блоки кода (opt-in, превью первых строк)

**Дата:** 2026-07-03
**Сайт:** devtechblog.ru (Quartz v5.0.0)
**Статус:** утверждён дизайн, ожидает реализации

## Цель

Дать возможность помечать отдельные блоки кода в статьях так, чтобы они
отображались свёрнутыми по умолчанию: виден верх кода, низ затухает в фон,
внизу кнопка «Развернуть». Обычные блоки без пометки не меняются.

## Решения (подтверждены пользователем)

- **Охват:** opt-in — сворачиваются только блоки, явно помеченные флагом
  `collapse` в ограде кода. Непомеченные рендерятся как раньше.
- **Вид свёрнутого:** превью первых ~6 строк с плавным затуханием (fade)
  в фон темы и кнопкой «Развернуть код» на полоске затухания.
- **Реализация:** локальный плагин Quartz v5 (без форка чужих плагинов,
  переживает обновления).

## Синтаксис для автора

    ```python collapse
    # длинный код...
    ```

Слово `collapse` в meta ограды включает сворачивание для этого блока.
Порог по длине не применяется — сворачивается всё помеченное.

## Архитектура

Локальный плагин `quartz/plugins/local/collapse-code`, подключается через
`npx quartz plugin add ./quartz/plugins/local/collapse-code` (симлинк в
`.quartz/plugins/`). Реализует `QuartzTransformerPlugin` с тремя частями:

1. **`mdPlugins` (remark):** обходит mdast-узлы `code`; если в `node.meta`
   есть токен `collapse` — удаляет его из meta (чтобы rehype-pretty-code не
   спотыкался) и ставит `node.data.hProperties['data-collapse'] = 'true'`,
   которое переходит на элемент `<code>` при конвертации в hast.

2. **`externalResources().css`:** SCSS со свёрнутым состоянием —
   `figure:has(code[data-collapse])` ограничивает высоту `<pre>` (~6 строк),
   прячет переполнение, накладывает градиент-fade от `var(--light)` снизу.
   Свёрнуто уже в SSR (через `:has`), без мигания при загрузке. Класс
   `.code-expanded` снимает ограничение высоты и fade.

3. **`externalResources().js` (afterDOMReady):** для каждого
   `figure:has(code[data-collapse])` вставляет кнопку «⌄ Развернуть код»;
   по клику переключает класс `.code-expanded` на figure и подпись кнопки
   на «⌃ Свернуть».

Кнопка копирования (плагин `syntax-highlighting`) и подсветка синтаксиса
не затрагиваются.

## Параметры по умолчанию

- Высота превью: ~6 строк (`max-height`, легко поменять в SCSS).
- Подписи: «Развернуть код» / «Свернуть».
- Цвет fade: `var(--light)` (фон темы, корректно в light/dark).

## Риск и план проверки

Основной риск: переживёт ли `data-collapse` на `<code>` проход
`rehype-pretty-code` (он перестраивает `<pre>/<code>` в `<figure>`).

**Проверка (спайк):** пометить тестовый блок, собрать, посмотреть, есть ли
`data-collapse` в `public/*.html`.

**План Б, если атрибут теряется:** добавить в плагин второй проход
`htmlPlugins` (rehype) с `order` выше `syntax-highlighting`, который найдёт
маркер и поднимет класс/атрибут на `<figure>`. Альтернативно — переносить
маркер на обёртку, которую rehype-pretty-code не трогает.

## Вне охвата (YAGNI)

- Автоматическое сворачивание всех блоков.
- Порог по длине.
- Настройка высоты/подписей через UI или frontmatter (пока хардкод в плагине).
