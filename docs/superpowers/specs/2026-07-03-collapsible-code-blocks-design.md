# Сворачиваемые блоки кода (opt-in, превью первых строк)

**Дата:** 2026-07-03
**Сайт:** devtechblog.ru (Quartz v5.0.0)
**Статус:** дизайн утверждён и отревьюен, ожидает реализации

## Цель

Помечать отдельные блоки кода в статьях так, чтобы они отображались
свёрнутыми по умолчанию: виден верх кода, низ затухает в фон, внизу кнопка
«Развернуть». Обычные (непомеченные) блоки не меняются.

## Решения (подтверждены пользователем)

- **Охват:** opt-in — сворачиваются только блоки с флагом `collapse` в
  ограде кода. Непомеченные рендерятся как раньше.
- **Вид свёрнутого:** превью первых ~6 строк с плавным затуханием (fade) в
  фон темы и кнопкой «Развернуть код» на полоске затухания.
- **Реализация:** локальный плагин Quartz v5 (без форка чужих плагинов,
  переживает обновления).

## Синтаксис для автора

    ```python collapse
    # длинный код...
    ```

Слово `collapse` в meta ограды включает сворачивание для блока. Порог по
длине не применяется — сворачивается всё помеченное.

## Механизм рендера: чистый CSS, без клиентского JS (уточнено на ревью)

Свёрнутое состояние и переключение делаются **на CSS** через скрытый
`<input type="checkbox">` + `<label>` (disclosure-паттерн), которые плагин
вставляет в HTML на этапе сборки. Почему так, а не клиентский JS-скрипт
(как было в первой версии дизайна):

- **Нет мигания (FOUC):** блок свёрнут сразу в SSR-HTML, а не после
  выполнения JS.
- **Работает без JS:** контент не прячется за скриптом — переключение
  нативное (checkbox). Важно, т.к. сворачивание скрывает часть контента.
- Меньше рантайм-кода; подсветка и кнопка копирования не затрагиваются.

Компромисс: checkbox как disclosure озвучивается скринридером как
«флажок», а не «кнопка». Для личного блога приемлемо; текст лейбла ясный
(«Развернуть код»). При необходимости позже добавим `aria`/JS.

## Архитектура

Локальный плагин `quartz/plugins/local/collapse-code` — небольшой
npm-пакет, структуру берём с существующего минимального плагина
(`hard-line-breaks`: `package.json` с `build: tsup`, `tsconfig`,
`tsup.config.ts`, `src/`, сборка в `dist/`). Подключается:

    npx quartz plugin add ./quartz/plugins/local/collapse-code

(симлинк в `.quartz/plugins/`, пересборка при `plugin install`). В
`quartz.config.default.yaml` у плагина `order` > 20 (у `syntax-highlighting`
order = 20), чтобы наш rehype-проход шёл **после** rehype-pretty-code.

Плагин реализует `QuartzTransformerPlugin` из трёх частей:

1. **`mdPlugins` (remark):** обходит mdast-узлы `code`; если в `node.meta`
   есть токен `collapse` — удаляет его из meta (чтобы rehype-pretty-code не
   спотыкался) и ставит маркер, который дойдёт до hast. Ожидаемый механизм:
   `node.data.hProperties['data-collapse'] = 'true'` → атрибут на `<code>`.
   Точный механизм подтверждается спайком (см. Риски, R1).

2. **`htmlPlugins` (rehype, order > syntax-highlighting):** находит каждый
   помеченный `<figure data-rehype-pretty-code-figure>` (по дожившему
   маркеру), добавляет класс `code-collapsible` и вставляет внутрь скрытый
   `<input type="checkbox" class="code-collapse-toggle" id="cc-N">` и
   `<label for="cc-N" class="code-collapse-label">`. Уникальный `id` —
   через детерминированный счётчик на страницу (без random, для
   воспроизводимых сборок).

3. **`externalResources().css`:** SCSS свёрнутого состояния:
   - `figure.code-collapsible pre` → `max-height` ~6 строк, `overflow:hidden`,
     нижний градиент-fade от `var(--light)`, `position:relative`;
   - `figure.code-collapsible:has(> input.code-collapse-toggle:checked) pre`
     → `max-height:none`, без fade (развёрнуто);
   - `label` — центрированная «пилюля»-кнопка на полоске fade; текст
     «Развернуть код», меняется на «Свернуть» при `:checked`.

Клиентского JS плагин не добавляет.

## Параметры по умолчанию (хардкод в плагине, легко менять)

- Высота превью: ~6 строк (`max-height` в SCSS).
- Подписи: «Развернуть код» / «Свернуть».
- Цвет fade: `var(--light)` (фон темы, корректно в light/dark).

## Риски и проверки

- **R1 — выживание маркера через rehype-pretty-code (главный риск).**
  rehype-pretty-code перестраивает `<pre>/<code>` в `<figure>`; `data-collapse`
  на `<code>` может не сохраниться. **Спайк — первый шаг реализации:**
  пометить тестовый блок, собрать, проверить наличие маркера в `public/*.html`.
  Если теряется — запасные варианты: (a) маркер как `className` на `code`;
  (b) собрать в `mdPlugins` список помеченных блоков и в rehype-проходе
  сопоставить `<figure>` по порядку следования в документе.

- **R2 — локальный плагин на Windows и в CI.** Локальный плагин ставится
  симлинком (на Windows может требовать прав/dev-режима) и должен также
  ставиться в CI (чистый Linux-checkout: `npx quartz plugin install` берёт
  локальный источник из `quartz.lock.json`). Проверить: локальная сборка на
  машине пользователя **и** прогон сборки как в CI.

- **R3 — CSS `:has()`.** Используется для состояния «развёрнуто».
  Поддержка в актуальных браузерах (2023+) есть; для блога приемлемо.

- **R4 — кнопка копирования.** Скрипт `syntax-highlighting` (afterDOMReady)
  ищет `pre`/`figure`; после вставки наших узлов он должен продолжать
  работать. Проверить в сборке/спайке.

- **R5 — a11y.** См. раздел про механизм: checkbox-disclosure приемлем,
  лейбл ясный.

## Тестирование

- Спайк подтверждает механизм маркера (R1).
- Тестовая статья в `content/` с двумя блоками: помеченным `collapse` и
  обычным. Сборка `npx quartz build`, проверка HTML/CSS: помеченный
  свёрнут и содержит toggle, обычный без изменений.
- Юнит-тест плагина (vitest, как в соседних плагинах): mdPlugins ставит
  маркер и вырезает `collapse` из meta; блок без флага не трогается.

## Вне охвата (YAGNI)

- Автоматическое сворачивание всех блоков.
- Порог по длине.
- Настройка высоты/подписей через frontmatter или UI (пока хардкод).
